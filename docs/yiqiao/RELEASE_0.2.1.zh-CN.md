# YiQiao 0.2.1

**简体中文** | [English](RELEASE_0.2.1.md)

YiQiao 0.2.1 是一个聚焦于精确记忆去重的维护版本。

## 变更

- 在推断写入和原文写入（`infer=false`）两条路径中阻止完全重复的记忆落库。
- 计算记忆指纹前，统一规范 Unicode 格式字符和空白字符。
- 对同一项目和实体作用域的并发写入进行串行化，并使用确定性 ID，使请求重试最终收敛到同一条记录。
- 独立检查精确指纹，不再依赖语义检索前若干条结果是否包含已有记忆。
- 在工作台中增加清理操作：每组完全重复记忆保留最早的一条，删除其余记录，并同步清理图谱和反馈数据。

去重仅作用于相同 `project_id`、`user_id`、`agent_id`、`app_id` 和 `run_id`
作用域中的完全等价内容，不会根据模糊相似度删除记忆。

## 升级

拉取 `v0.2.1` 镜像，或检出 `v0.2.1` 标签后重新启动服务。升级完成后，可在
**工作台 > 记忆 > 清理重复项**中清理已有的完全重复记忆。
